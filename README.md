# 🌏 Discover Bihar

### Explore the Heritage, Culture, Food & Hidden Gems of Bihar

**Discover Bihar** is a responsive tourism and cultural exploration website designed to showcase the rich **history, heritage, culture, traditional food, festivals, art, famous personalities, hidden destinations, and travel experiences of Bihar**.

The project aims to bring Bihar's diverse cultural and tourism information together on a modern, visually appealing and user-friendly platform.

🔗 **Live Website:** https://discover-bihar.vercel.app/

---

## 📌 Project Overview

Bihar is one of India's most historically and culturally significant states. From ancient universities and Buddhist heritage sites to traditional art, festivals and local cuisine, Bihar has a wide range of attractions to explore.

**Discover Bihar** presents this information in an organized and interactive web interface so that visitors can easily explore different aspects of Bihar from a single platform.

The website is developed with a focus on:

* Clean and modern UI
* Easy navigation
* Responsive design
* Cultural storytelling
* Tourism discovery
* Mobile-friendly experience

---

## ✨ Key Features

### 🏛️ Heritage

Explore Bihar's historical and heritage destinations, including important monuments, temples and historically significant places.

### 🌿 Hidden Places

Discover lesser-known destinations and natural attractions of Bihar that are often overlooked by mainstream tourism.

### 🍛 Food & Cuisine

Learn about traditional Bihari dishes and local delicacies such as:

* Litti Chokha
* Khaja
* Thekua
* Malpua

### 🎉 Festivals

Explore Bihar's major festivals and cultural celebrations, including:

* Chhath Puja
* Sonepur Mela
* Jitiya
* Other regional celebrations

### 🎨 Art & Culture

Discover Bihar's traditional art and handicrafts, including:

* Madhubani Art
* Sujuni
* Sikki Craft

### 👤 Famous Personalities

Learn about notable personalities associated with Bihar and their contributions to history, science, literature and society.

### 📸 Gallery

A visual collection highlighting Bihar's:

* Heritage
* Landscapes
* Food
* Festivals
* Art & Culture

### 🧭 Travel Guide

The Travel Guide provides useful information about:

* Best time to visit
* Transportation
* Travel styles
* Suggested destinations
* Sample travel itinerary

## ⚙️ How to Run the Project Locally

### 1. Clone the Repository

```bash
git clone https://github.com/uditanshusiingh/Discover-Bihar
```

### 2. Open the Project

```bash
cd Discover-Bihar
```

### 3. Run the Website

Since this is a frontend project, you can open `index.html` directly in a browser.

For a better development experience, use **Visual Studio Code with Live Server**.

### 4. Open in Browser

The website will be available through the local development server, for example:

```text
http://127.0.0.1:5500/
```

## 🔍 Research & Development

Before developing the website, research was conducted on various aspects of Bihar, including:

* Historical places

* Traditional cuisine
